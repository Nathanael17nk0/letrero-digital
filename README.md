# Letrero LED Digital

Aplicación web interactiva de letrero digital tipo marquesina LED con efectos de iluminación, personalización tipográfica y modo pantalla completa optimizado para móviles y pantallas de gran formato.

## Características

- 💡 **Simulación de Matriz LED**: Renderizado nítido con efectos de brillo y glow neón.
- 📱 **Modo Móvil y Rotación**: Diseñado para usarse horizontalmente en teléfonos inteligentes.
- 🎨 **Paletas y Estilos**: Múltiples colores, fuentes vintage/pixel y velocidades configurables.
- ⚡ **100% Estático**: Sin dependencias complejas, funciona en cualquier navegador web moderno.
